Minote — Privacy & Security Experience
An interactive product prototype developed for a real-world innovation challenge with Minote.
DTU Innovation Pilot · Summer 2026 · Industry-facing prototype
Project status: Interactive concept prototype — not a production security system.

The challenge
Personal memories stored in the cloud may be deeply private, yet people often have limited visibility into how their data is stored, protected and shared. Our initial question focused on choosing a storage location. Research and user interviews revealed a broader challenge: making privacy understandable and giving people meaningful control without complicating the memory experience.

Design question: How might we help users make informed decisions about personal cloud storage through greater transparency, trust and control?
The solution
We designed and developed an interactive prototype that extends Minote's existing memory experience rather than replacing it with a separate service. The prototype demonstrates:
Feature	Purpose
Privacy Center	Bring key privacy and security information into one accessible place
Memory PIN	Demonstrate an additional access step for private memories
Storage preferences	Let users express a preferred storage region or no preference
Encryption information	Explain the intended protection of memories in understandable language
Sharing controls	Make third-party sharing choices visible
Privacy Assistant	Explain privacy settings in simple terms


The interface connects these concepts to the ordinary journey of creating, saving and viewing memories.

Process and iteration
Discover → Define → Develop → Deliver
1. Discover: Researched cloud storage, privacy and trust; gathered user perspectives through interviews.
2. Define: Reframed the initial storage-location problem around transparency, privacy and control.
3. Develop: Explored ideas, created wireframes and developed an interactive website prototype.
4. Deliver: Tested and refined the concept, presented it to Minote and incorporated feedback.
What changed after feedback
Minote challenged the initial direction because it appeared to create a separate platform. We redesigned the experience so that privacy features were integrated into the existing memory journey. We also made privacy controls more visible and clarified explanations of the proposed protections.
What the prototype proves — and does not
The prototype demonstrates user journeys, interactions, product concepts and communication of privacy choices. It does not establish that real encryption, secure PIN storage, access-control enforcement or cloud-region selection were implemented or independently security-tested. Those would require backend development, technical validation and additional security engineering before production use.

Key takeaways
- User research can fundamentally change the problem a product should solve.
- A useful feature needs to fit naturally within an existing product experience.
- Privacy is not only an engineering challenge; people must be able to understand their choices.
- Prototypes should communicate clearly what is demonstrated and what remains to be implemented.
